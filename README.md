# 📰 توزيعة الأخبار

توزيعة الأخبار مبنية على نظام إدارة المحتوى **Backdrop CMS** المعروف بمرونته، سهولته، ومميزاته العالية. ما يميز هذا النظام أن الأشخاص غير التقنيين يمكنهم إدارته والتعامل معه بكل سهولة. التوزيعة مجانية بالكامل، وهي من المشاريع مفتوحة المصدر التي تتلقى تحديثات مستمرة، مما يضمن أمان الموقع واستمرار تطويره من قِبل مجتمع المطورين.

---

## ✨ مميزات التوزيعة

1. **سهولة التثبيت:** تتوفر جميع متطلبات تشغيل التوزيعة في معظم شركات الاستضافة القياسية.
2. **إدارة نظام مرنة:** يحتوي النظام على أدوات مهمة تسهل وتختصر الوقت أثناء تطوير الموقع وتخصيصه.
3. **نظام صلاحيات متطور:** تتيح لوحة التحكم إدارة مجموعات الأعضاء والصلاحيات بدقة، والتحكم الكامل في إضافة المحتوى وتعديله، مع إمكانية تحديد صلاحيات الحقول بشكل متقدم جداً.
4. **أداة الرؤى السحرية (Views):** تمكّنك من الاستعلام من قاعدة البيانات وتصدير واستعراض البيانات في الموقع مباشرة من لوحة التحكم، دون الحاجة لكتابة كود PHP واحد.
5. **أداة التصميم المرنة (Layouts):** تمنح المصممين تحكماً كاملاً في ظهور الصناديق داخل الموقع، ووضع شروط لظهورها في صفحات محددة، مع إمكانية إضافة وسوم HTML وفئات CSS (Classes) مباشرة من خيارات الصناديق.
6. **جاهزة ومستقرة:** لن تحتاج بعد تثبيت التوزيعة إلى تحديثات مستمرة لها، لأنك تحتاج لإعدادها عند التثبيت لأول مرة فقط.

---

## 🛠️ متطلبات التشغيل وطريقة التثبيت (Installation)

تعمل التوزيعة على أغلب الاستضافات المشتركة والسيرفرات الخاصة التي تدعم تشغيل أنظمة PHP و MySQL.

### 1️⃣ المتطلبات الأساسية:
* **خادم الويب:** Apache أو Nginx
* **إصدار PHP:** 7.4 أو أحدث
* **قاعدة البيانات:** MySQL أو MariaDB

### 2️⃣ خطوات التثبيت السريع:
1. **تحميل التوزيعة:** قم بتحميل ملفات التوزيعة بالضغط على زر **Code** ثم **Download ZIP** من الأعلى، أو عبر أمر `git clone` في جهازك.
2. **رفع الملفات:** ارفع الملفات إلى مجلد الاستضافة الرئيسي الخاص بك (مثل `public_html`).
3. **إنشاء قاعدة البيانات:** قم بإنشاء قاعدة بيانات مستخدم جديدة (MySQL Database) من لوحة تحكم استضافتك (cPanel).
4. **بدء معالج التثبيت:** افتح رابط موقعك في المتصفح، واتبع خطوات معالج التثبيت السهل لإدخال بيانات قاعدة البيانات وإعداد حساب المدير.
